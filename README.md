# AudienClature

## Overview
AudienClature is a music player designed for an engaging and immersive audio experience. 

## Features
- **Intuitive Interface:** Developed with Angular, styled using MDBootstrap and SCSS, AudienClature offers a sleek, responsive user experience.
- **Dynamic Playlist Management:** Easily organize your music, create playlists, and explore your collection.
- **Responsive Design:** Optimized for both desktop and mobile devices, ensuring a seamless experience.
- **Customizable Themes:** Personalize the appearance of the player to match your style.

## Exciting New Features

### Interactive Globe for Global Radio (Work in Progress)
- **Global Station Exploration:** Discover and tune into radio stations worldwide with an interactive 3D globe.
- **Status:** This feature is currently in development, aimed at delivering an engaging and comprehensive listening experience.

### Smart Song Switching Based on Lyrics (Work in Progress)
- **Lyric-Based Song Transition:** A novel feature that will allow the music player to switch songs based on the current lyrics being played.
- **Innovative Listening Experience:** Enhance your music journey with this intelligent and context-aware functionality.
- **Status:** This feature is under development, with a focus on creating a smooth and intuitive user interface that integrates seamlessly with the existing functionalities.
